Hyster J1.5XNT

Maqueta educativa de un forklift eléctrico de tres ruedas y 1,5 t de capacidad nominal.

Cargando escena 3D…

Arrastrá para girar la cámara. Usá la rueda o dos dedos para acercarte.

Controles

Conducción
Mástil y horquillas
Mantené pulsado un botón o usá W/S para mover, A/D para girar, Q/E para subir y bajar, Z/X para inclinar. En esta maqueta podés orientar el vehículo detenido.

Práctica de carga

Alineá el forklift, avanzá para meter las horquillas y levantá la carga. Bajala al piso para soltarla.

Elegí un pallet para comenzar.

Simulación ilustrativa. El vuelco está programado para mostrar el riesgo de sobrecarga. La capacidad real depende de la placa de carga y de la configuración del equipo.

Partes del forklift

Seleccioná una pieza para resaltarla y conocer su función.
